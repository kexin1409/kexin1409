# 高性价比 · 循证科普系列

你好，我是「高性价比」系列的作者。

我把市面上互相矛盾、动辄贩卖焦虑的养生 / 理财 / 保健内容，筛成一份**按性价比排好、每条可溯源**的备选单——你不必全做，挑走一两条就算数。

## 我怎么做这套书

- 每一条都是一张标准卡片：**成本**（钱 / 时间 / 毅力）· **说人话** · **收益** · **证据等级**（A 强 / B 中 / C 弱）· **风险** · **来源** · **备注**
- 证据只引权威来源：公开研究、官方文件（人社、财政、卫健）、临床指南（USPSTF、国家癌症中心）、经典著作
- 不站队、不煽动、不灌鸡汤；结论可能过时或有错，决策请独立作出
